# 弈古 App - 产品需求文档 (PRD)

## 一、产品概述

**产品名称**：弈古 (YiGu Xiangqi)  
**产品定位**：专注于"中国象棋古谱学习与互动训练"的移动端工具应用。  
**核心价值**：将经典象棋古谱装进口袋，通过逐步打谱、分支研究、互动猜招等功能，帮助象棋爱好者系统化提升棋力。  
**目标用户**：象棋初学者、进阶爱好者、需要随时随地查阅古谱的专业棋手。  
**完全离线**：所有古谱数据内置于 App assets 中，核心引擎纯本地计算，无需联网。

---

## 二、导航结构

App 采用底部导航栏 (Bottom Navigation) + 堆栈导航的混合结构：

```
底部四 Tab：
├── 首页 (Home)       → 书架、继续学习、每日推荐
├── 学习 (Study)      → 学习路径、最近学习
├── 收藏 (Favorite)   → 收藏棋局、学习记录、笔记
└── 我的 (Profile)    → 统计数据、偏好设置

堆栈页面（从 Tab 页深入）：
├── 棋局列表 (GameList)  → 某古谱下的所有对局
└── 打谱棋盘 (Board)     → 核心打谱/猜招界面
```

## 三、核心功能模块详述

### 1. 首页 (Home)

#### 1.1 学习统计卡片
- 显示"已学 X / Y 局"（X = 存在学习进度的棋局总数，包含学习中与已完成，Y = 当前展示书架的总局数）
- 显示"学习 N 天"（按自然日去重的累计学习天数）

#### 1.2 继续学习
- 展示最后一局处于"学习中"状态的棋局（标题、所属古谱、当前步/总步）
- 点击直接跳转到上次退出时的步数

#### 1.3 每日推荐
- 随机推荐一局用户尚未完成的棋局
- 点击直接进入打谱

#### 1.4 古谱书架
- 展示所有内置古谱（30+ 部），每个卡片显示：
  - 古谱名称
  - 类型标签（全局 / 残局）
  - 包含棋局总数
  - 学习进度条（已学/总数）
- **排序**：默认顺序 / 最近访问 / 访问次数 / 添加时间（正/倒序切换）
- **筛选**：全部 / 全局 / 残局 标签切换
- **视图切换**：网格视图 / 列表视图
- 点击古谱 → 进入棋局列表

---

### 2. 棋局列表 (GameList)

#### 2.1 页面内容
- 顶部显示古谱名称、类型、总局数
- 搜索框：按棋局标题搜索
- 棋局行显示：标题、对局结果、步数、是否有变着、是否有评注

#### 2.2 学习状态标记
- **绿色对勾 ✓ + "X遍"**：该局已从头到尾完整学完至少一遍（`completionCount ≥ 1`）
  - 只要有完成记录，列表右侧就会以绿色文字明确显示具体的学习次数（如"1遍"、"2遍"等），并附带绿色的对勾图标。
- **"学习中"**：进入过且有进度但尚未看完（`status = IN_PROGRESS`）
- **无标记**：从未开始学习

#### 2.3 学习次数与状态流转判定标准
- **打开次数 (viewCount)**：只要进入打谱页面就算作一次。
- **学习次数 (completionCount)**：从头到尾完整看完一遍（导航到最后一步），才计为完成一次学习。不计入仅进入后退出或只看了几步的情况。
- 只有真正的完成学习（`completionCount` 增加）才会反映在书架列表的进度条、以及首页顶部“已学”的总局数统计中。
- **状态流转 (StudyStatus)**：
  - NOT_STARTED → (进入棋盘，走了至少一步) → IN_PROGRESS → (看到最后一步) → COMPLETED
  - COMPLETED 后 `completionCount + 1`。已经 COMPLETED 的棋局再次进入，状态保持 COMPLETED。

#### 2.4 排序与筛选
- 支持多种排序方式切换：默认排序、最近访问、访问最多、访问最少、学习最多、学习最少。
  - **最近访问**依据的是该棋局真实的最后学习时间（`lastStudiedAt`），不仅进入棋局会更新，任何后续的步进、打谱等操作都会实时更新。

---

### 3. 打谱棋盘 (Board) —— 核心功能

#### 3.1 阅读模式（默认）
- **步进导航**：首步 / 上一步 / 下一步 / 末步。底部控制栏采用沉浸式设计，自然融入页面，去除悬浮阴影。
- **自动播放**：按设定间隔自动前进，到末尾自动停止。播放按钮在控制栏中突出显示。
- **着法列表**：红黑双方历史着法配对显示，点击可跳转至该步。当前步高亮背景（阴影）仅包裹文字本身，采用圆角矩形设计，避免整行高亮导致比例失调。
- **古谱评注**：当前步若有评注，以卡片形式同步展示
- **视角翻转**：红方在下 ⇆ 黑方在下

#### 3.2 变着与分支
- 在有变着的步数显示"变着入口"芯片（Variation Chips）
- 进入变着后顶部出现面包屑导航（如：主线 > 变着1 > 变着2）
- 支持：进入变着、退出当前变着、直接返回主线

#### 3.3 猜招模式
- 一键切换，自动回到首步
- 棋盘交互：选中己方棋子 → 点击目标格猜测下一步
- 猜对：自动走对方应招并继续；猜错：红字提示
- 顶部实时显示猜招正确率（正确数/总尝试数）

#### 3.4 进度保存与恢复
- 每次步进/后退自动保存当前步数
- 下次打开同一棋局自动恢复到上次位置
- 到达末尾标记为 COMPLETED，`completionCount + 1`

#### 3.5 学习会话 (Session)
- 进入棋盘时创建一个 StudySession 记录
- 退出时关闭 Session，记录到达步数、是否完成、猜招数据
- 用于统计学习时长和行为分析

#### 3.6 收藏
- 点击心形图标收藏/取消收藏当前棋局

#### 3.7 棋盘内设置
- 自动播放速度（0.5 ~ 5 秒/步）
- 走棋高亮样式
- 落子特效
- 音效类型

---

### 4. 学习 Tab (Study)

#### 4.1 每日推荐
- 同首页逻辑，随机一局未完成棋局

#### 4.2 学习路径
- 预设 5 个阶段性学习路线（入门 → 高级），每阶段推荐若干古谱
- 目前为展示型卡片，不可交互导航

#### 4.3 最近学习
- 展示最近 10 条有进度的棋局记录

---

### 5. 收藏 Tab (Favorite)

三个子标签页：

| 标签 | 内容 |
|------|------|
| 收藏 | 用户收藏的棋局列表，点击进入打谱 |
| 记录 | 所有学习过的棋局历史，含进度信息 |
| 笔记 | 用户的文字笔记列表 |

各子页无内容时展示空状态提示。

---

### 6. 我的 Tab (Profile)

#### 6.1 学习统计
- 已完成棋局数
- 累计学习天数
- 猜招正确率（全局正确/总尝试）

#### 6.2 偏好设置
- **自动播放速度**：0.5s ~ 5s/步
- **走棋高亮样式**：天天象棋风格 / 圆环 / 四角 / 矩形 / 无
- **落子特效**：天天象棋风格（默认）/ 淡入淡出 / 弹跳 / 脉冲 / 无
- **音效类型**：木质 / 石质 / 玉质 / 金属 / 竹质 / 无

#### 6.3 关于
- 版本号 v1.0.0

## 四、数据模型

### 核心实体

| 实体 | 说明 |
|------|------|
| `ManualEntity` | 古谱元数据：名称、类型、总局数、添加时间、最近访问时间、访问计数 |
| `GameEntity` | 棋局完整数据：标题、结果、红/黑棋手、初始布局 JSON、走法 JSON、变着 JSON、评注 JSON |
| `UserProgressEntity` | 学习进度：状态、当前步、完成次数(completionCount)、打开次数(viewCount)、猜招数据、时间戳 |
| `FavoriteEntity` | 收藏记录：棋局 ID、时间 |
| `UserNoteEntity` | 笔记：棋局 ID、步数、分支路径、内容 |
| `StudySessionEntity` | 学习会话：棋局 ID、模式、开始/结束时间、到达步数、是否完成 |

### 关键状态流转

```
StudyStatus:
  NOT_STARTED → (进入棋盘，走了至少一步) → IN_PROGRESS → (看到最后一步) → COMPLETED
```

- COMPLETED 后 `completionCount + 1`
- 已经 COMPLETED 的棋局再次进入，状态保持 COMPLETED
- 书架列表及首页的“已学”总数，均依赖 `completionCount > 0` 的真实学完局数进行计算，而不是以打开算作已学。

---

## 五、数据导入流程

1. App 首次启动（或有新古谱 JSON 加入 assets 时）触发 `DataImporter`
2. 扫描 `assets/manuals/*.json`
3. 已有且局数匹配的古谱跳过
4. 解析 JSON → 批量插入 Manual + Game 到 Room 数据库
5. Game ID 格式：`{manualId}:{game.id}`

---

## 六、非功能性需求

1. **完全离线**：古谱数据内置 assets，核心引擎纯本地，无网络依赖
2. **性能**：
   - 棋盘使用原生 Canvas 绘制，60fps 流畅动画
   - 大容量古谱（200+ 局）快速解析和渲染
3. **UI/UX**：Material Design 3 + Jetpack Compose，响应式布局
4. **数据持久化**：Room 数据库存储进度/收藏/笔记；DataStore 存储偏好设置

---

## 七、技术架构

- **架构模式**：MVVM + 单向数据流
- **UI**：Jetpack Compose + Navigation Compose
- **DI**：Hilt
- **数据库**：Room（v4，含迁移）
- **偏好**：DataStore（`yigu_settings` + `ui_preferences` 两个实例）
- **状态管理**：StateFlow → Compose collectAsState
- **游戏引擎**：纯 Kotlin 实现的 `GameEngine`（步进、分支、猜招），不做合法性校验，仅匹配记录着法
