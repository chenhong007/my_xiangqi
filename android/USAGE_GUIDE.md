# 🎯 落子效果系统使用说明

## 概览

为您的象棋应用添加了专业级的**可配置落子效果系统**，提供5种不同的视觉设计风格。用户可以根据个人偏好选择喜欢的效果。

## 🔧 配置说明

### 默认配置
```kotlin
// 系统默认使用天天象棋风格
val config = PieceDropEffectConfig(
    type = PieceDropEffectType.TIANTIAN_XIANGQI,
    duration = 400,      // 400 毫秒
    originScale = 0.3f,  // 30% 棋子大小
    dropDuration = 0.7f, // 70% 时间用于落地
)
```

### 动画时间分布
```
0ms          280ms        400ms
|------------|------------|
   落地阶段      后效应阶段
   (70%)         (30%)
   ↓             ↓
圆心→棋子   光晕脉冲衰减
```

### 自定义参数
修改 `BoardViewModel` 中的配置：
```kotlin
// 修改时长（例如：600ms）
viewModel.setPieceDropEffect(
    PieceDropEffectPresets.TIANTIAN_XIANGQI_SLOW
)
```

## 🐛 常见问题

### Q1: 效果太快或太慢？
**A:** 选择不同的预设版本
- 快速版：`PieceDropEffectPresets.TIANTIAN_XIANGQI_FAST`
- 舒缓版：`PieceDropEffectPresets.TIANTIAN_XIANGQI_SLOW`

### Q2: 如何禁用效果？
**A:** 选择"无动画"模式或设置 `duration = 0`

### Q3: 低端设备性能差？
**A:** 使用"无动画"或"简约"模式，零/最小化性能开销

### Q4: 能自定义新效果？
**A:** 可以！在 `PieceDropEffectRenderer` 中添加新方法

### Q5: 如何修改动画时长？
**A:** 修改 `PieceDropEffectConfig` 中的 `duration` 参数

### Q6: 效果会影响游戏流畅度吗？
**A:** 不会。动画采用 GPU 加速，仅在动画期间活跃

### Q7: 用户的选择会保存吗？
**A:** 是的。使用 DataStore 自动保存到本地

### Q8: 不同设备间能同步吗？
**A:** 目前在本地保存。可在未来添加云同步

## 🎓 技术深度

### 动画原理
```
Compose Animatable → LaunchedEffect 监听
                 ↓
              Canvas 重绘
                 ↓
            DrawScope.drawPieceDropEffect()
                 ↓
            调用对应效果绘制函数
                 ↓
              屏幕显示
```

### 数据流
```
用户选择 → ViewModel.setPieceDropEffect()
            ↓
       UIPreferencesManager.setPieceDropEffect()
            ↓
        DataStore 保存
            ↓
        Flow 发射更新
            ↓
       ViewModel 更新 State
            ↓
         UI 重新组合
            ↓
       BoardCanvas 重绘
```
